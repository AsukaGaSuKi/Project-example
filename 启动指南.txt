【三步跑起来】
1. 安装依赖（一次性）：
   cd inspection-bot\backend
   pip install -r requirements.txt
   （装得慢就加国内镜像：pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple）

2. 启动：
   python -m uvicorn main:app --reload

3. 浏览器打开：
   http://127.0.0.1:8000       控制台（自动消防小车）
   http://127.0.0.1:8000/docs  接口调试台

【跑单元测试】
   cd inspection-bot\backend
   python -m pytest tests
   看到「15 passed」就说明代码是好的。

【演示顺序（照着点就行）】
   1) 等 6 秒：自动出现火情 → 右侧「全车自检」六项逐项变绿 → 小车出发灭火
   2) 点「🚧 前方放路障」：小车停车，机械臂伸出把路障移走
   3) 点「🛠 注入故障」：自检失败 → 自动去维修站 → 修好后重新自检
   4) 多点几次「🔥 模拟火情」：水量低于 10% 仍可灭火，耗尽后自动去最近补水站
   5) 看行人：只走人行道/斑马线，红灯在路口等待；小车遇到行人会明显降速

【文件是谁的地盘】
   backend/sim/city.py             城市路网、人行道、站点、火情点位
   backend/sim/world.py            消防车状态机、行人、火情、机械臂、自检
   backend/algo/pathfinding.py     BFS / A*（网格版 + 通用加权图版）
   backend/ai/detector.py          告警规则
   backend/static/index.html       Canvas 控制台
   backend/main.py                 HTTP 接口 + 仿真心跳
   backend/tests/                  自动验题器
   dockerfile / docker-compose.yml / .github/   部署与流水线

【铁律】
   改完自己的文件 → 跑测试 → commit → push → 发 PR 让队友看一眼 → 合并。
